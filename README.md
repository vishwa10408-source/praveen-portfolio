# Cybersecurity React Portfolio

Professional cybersecurity portfolio built with React + Vite.

## Start

```bash
npm install
npm run dev
```

## Main details to change

Open:

`src/data/portfolio.js`

Change:

- name
- role
- email
- location
- GitHub
- LinkedIn
- about text
- skills
- projects
- experience

## Add your photo

Put your image here:

`public/profile.jpg`

If your image is named differently, change this line in `src/App.jsx`:

```jsx
src="/profile.jpg"
```

## Add your resume

Put your resume here:

`public/resume.pdf`

## Important

The sample cybersecurity projects are templates. Replace them with projects/labs you have actually completed before using the portfolio in an interview.
